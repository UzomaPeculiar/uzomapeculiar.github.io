Python Projects

Financial Loan Analysis

This project analyzes a financial loan dataset to evaluate portfolio performance and risk. We use Pandas, Numpy, Matplotlib, Seaborn, and Plotly for data cleaning, aggregation, and visualization. The analysis covers loan applications, funded amounts, repayments, and borrower characteristics.

Marathon Analysis

The project analyzes 2020 USA ultramarathon data (50km/50mi) using Python, Pandas, and Seaborn, cleaning data and exploring athlete age, performance, speed, and race popularity to provide insights for organizers and athletes.

Air BnB

This project performs Exploratory Data Analysis (EDA) on New York Airbnb data to uncover trends and patterns in rental listings. We use libraries like Pandas, Numpy, Matplotlib, Seabornfor cleaning, visualization, and analysis.

Movies Correlation

The project analyzes movie data to find correlations between budget, gross revenue, votes, and runtime using Python, Pandas, and Seaborn, visualizing results with a correlation heatmap.

YouTube Analysis

This project explores data from top YouTube streamers to uncover patterns in audience engagement and content popularity. The insights can help inform content strategies and marketing decisions on the platform.
